# Geospatial-Analysis-of-Urban-Infrastructure-Using-WebGIS



##  Project Overview

This project focuses on analyzing and visualizing **urban infrastructure in Bangalore using Geospatial Analysis and WebGIS**. It analyzes primary roads, hospital locations, and specific areas such as **Indiranagar** to understand the spatial relationship between urban infrastructure.

The final results are displayed using **interactive web-based maps**.

---

##  Project Workflow

```text
Spatial Data Collection
        ↓
Data Loading & Processing
        ↓
Geospatial Data Analysis
        ↓
Road & Hospital Analysis
        ↓
Spatial Operations (Filtering / Dissolve)
        ↓
Interactive WebGIS Visualization
```

---

##  Features

- Analysis of Bangalore's primary road network
- Visualization of hospitals and healthcare infrastructure
- Road analysis for Indiranagar
- Spatial filtering and geographic data processing
- Dissolve operation for geographic features
- Interactive WebGIS maps

---

##  Technologies Used

- **Python** – Programming and data processing
- **GeoPandas** – Geospatial data analysis
- **Shapely** – Geometry and spatial operations
- **Pandas** – Data manipulation
- **Folium** – Interactive WebGIS maps
- **Leaflet.js** – Interactive map visualization
- **Jupyter Notebook** – Development environment
- **Git & GitHub** – Version control and project hosting

## Project Outputs

-  **Bangalore Primary Roads**
-  **Bangalore Primary Roads and Hospitals**
-  **Indiranagar Roads**
-  **Dissolve Comparison**

All outputs are generated as interactive **HTML WebGIS maps**.
